# ポストに届く物語 LP

GitHub Pagesで公開できる、1ページLPの雛形です。

## ファイル構成

- `index.html`
- `styles.css`
- `script.js`

## 使い方

1. GitHubで新しいリポジトリを作成します。
2. この3ファイルをアップロードします。
3. `script.js` の `GOOGLE_FORM_URL` を、自分のGoogleフォームURLに差し替えます。
4. `index.html` の問い合わせメール `YOUR_EMAIL@example.com` を差し替えます。
5. GitHub Pagesを有効化します。

## QR計測用URL例

エリアごとにQRコードを分ける場合は、公開URLの末尾に以下のように付けます。

- 近所Aエリア: `https://あなたのURL/?area=A`
- 比較Bエリア: `https://あなたのURL/?area=B`
- カフェ設置: `https://あなたのURL/?area=C`
